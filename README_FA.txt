# NOVA Online Starter (نسخه آزمایشی)

این بسته یک نمونه ساده برای چت آنلاین اتاقی است. برای کارکرد واقعی باید سرور Node.js را روی یک میزبان اینترنتی اجرا کنید.

## محتویات
- `public/index.html` : صفحه وب نُوا
- `server.js` : سرور پیام‌رسان با Socket.IO
- `package.json` : وابستگی‌های سرور

## اجرای سرور روی رایانه یا میزبان Node.js
1. Node.js نسخه 18 یا جدیدتر نصب باشد.
2. در پوشه پروژه اجرا کنید:
   `npm install`
3. سپس:
   `npm start`
4. سرور روی پورت 3000 اجرا می‌شود. صفحه را از آدرس سرور باز کنید.

## نکته برای میزبانی
اگر میزبان شما PORT را خودش تعیین می‌کند، سرور از `process.env.PORT` استفاده می‌کند.
صفحه HTML از همان سرور استفاده می‌کند (`SERVER_URL=''`). پس فایل را از همان آدرس میزبان باز کنید؛ صرفاً باز کردن فایل محلی با `file://` برای چت اینترنتی کافی نیست.

## آزمایش دو گوشی
هر دو گوشی آدرس وب یکسان را باز کنند، نام‌های متفاوت انتخاب کنند و دقیقاً یک نام اتاق وارد کنند (مثلاً `nova-room`)، سپس «ورود به اتاق» را بزنند.

## محدودیت‌ها
- نسخه آموزشی و آزمایشی است؛ احراز هویت، رمزنگاری سرتاسری، پایگاه داده پایدار، مدیریت سوءاستفاده و فایل/عکس ندارد.
- تاریخچه فقط در حافظه سرور است و با خاموش یا راه‌اندازی مجدد سرور پاک می‌شود.
- برای انتشار عمومی، امنیت، حریم خصوصی، محدودیت نرخ، ذخیره‌سازی امن و سیاست‌های سرویس باید تکمیل شوند.
